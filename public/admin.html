Importar PDF, DOCX ou página salva

O conteúdo vira mainContent em HTML, no mesmo modelo dos outros artigos (surpresas, FAQ etc. ficam vazios até você editar depois). PDF usa só o texto extraído; linhas começando com ## viram subtítulo. HTML / MHTML só funcionam para páginas com texto no HTML (blog, artigo). Não use “guardar página” enquanto o PDF está aberto no Opera/Chrome: o que importa é o leitor (aparece só “-- 1 of 13 --” etc.) — nesse caso envie o ficheiro .pdf real ou um .docx. À direita: o mesmo JSON padrão do POST /api/articles / aba Publicar texto pronto → JSON, para copiar sem abrir a documentação.

Links de mídia

Campos de YouTube e podcast vazios usam o padrão do site (código em src/lib/article-defaults.ts e, se existir, DEFAULT_VIDEO_* / DEFAULT_PODCAST_* no .env). Preencha só quando este artigo tiver outro link. Limpar um campo e salvar remove o valor gravado e volta ao padrão.

Salve com os links de mídia ou só para atualizar visibilidade.
